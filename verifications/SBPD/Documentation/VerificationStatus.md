# SBPD 验证状态

## 结论

SBPD 当前不能标记为“已完成论文验证”。它是一个可以独立构建的 Lean 包，包含若干与文献符号对应的定义和局部定理，但还没有完成从论文假设、连续方程、离散化、材料本构、失效更新到数值结论的闭合证明链。

## 已经由 Lean 检查的片段

- 参考键和变形键交换后的反对称性。
- horizon 邻域交换对称性。
- 在调用者提供形状张量左右逆证书时，非局部变形梯度乘形状张量的代数恒等式。
- 直接定义为 `state i j - state j i` 的成对态力的反对称性和总和为零。
- 在离散运动方程谓词成立时的总惯性力与总外力平衡。
- 正交各向异性工程常数的部分代数公式和约化刚度正性。
- 零铺层角应力变换恒等式。
- Hoffman 指标阈值定义和端点交换对称性。
- 基于存活键体积的局部损伤边界和不可逆布尔状态更新。
- 有限厚度片段上的 `A/B/D` 刚度求和公式和 `M = B ε⁰ + D κ` 弯矩结果公式。
- 论文 `σ̂ = det(F) τ F⁻ᵀ` 应力测度和 `T = ω σ̂ K X` 有限点力态展开，以及层片膜力/弯矩贡献求和。
- PMB 断裂能临界伸长率反解、纤维/基体临界伸长率恢复恒等式和界面刚度恢复恒等式。
- BK 准则在纯 I 和纯 II 模式下分别恢复 `G_Ic` 与 `G_IIc`。

## 尚未证明的关键桥接

1. `ShapeTensorCertificate` 是外部输入，包内没有证明实际离散点集和影响函数会产生可逆形状张量。
2. `forceState` 尚未与论文中的连续力态积分、应力测度、形状张量约定和离散求积权重建立逐项等价。
3. `statePairForce` 的反对称性来自定义，尚未从论文的双端状态或本构互易性推导出来。
4. 复合材料本构尚未证明一般旋转角度下的应力/应变变换与论文矩阵完全一致。
5. ABD 的有限求和和弯矩结果函数已经加入，但尚未证明它们与连续层合板积分和论文中的一般铺层输入完全等价。层间 CZM、混合模式断裂能和分层状态更新仍未完成。
6. Hoffman 失效指标尚未连接到纤维、基体和层间三种损伤变量，也没有证明损伤后的本构矩阵更新。
7. 零能模式、人工阻尼、动态松弛和时间积分没有稳定性或收敛定理。
8. 论文中的 FEM 对比、实验对比和误差百分比属于数据证据，当前仓库没有形式化这些数值结果。

## 完成标准

只有在 `EquationMap.md` 中所有核心方程都具备 Lean 定理、明确假设和可重复构建记录，并且数值结论被单独标记为数据证据后，SBPD 才能称为完成论文级形式化验证。
