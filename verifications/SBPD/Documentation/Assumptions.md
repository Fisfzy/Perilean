# SBPD 假设清单

- A1：物质点数量有限，索引为 `Fin N`。
- A2：二维位置和位移采用 `Fin 2 → ℝ`，连续三维铺层和厚度积分暂未形式化。
- A3：每个物质点体积和密度严格为正。
- A4：不同物质点的参考位置具有正距离。
- A5：形状张量逆以 `ShapeTensorCertificate` 显式提供。当前包不把矩阵可逆性判定隐藏在定义中。
- A6：正交各向异性单层采用平面应力工程常数 `E1,E2,G12,ν12`，并假设约化刚度分母为正。
- A7：Hoffman 失效使用相邻物质点应力的平均值时，需要由调用者提供相应的应力状态。
- A8：层间键只按物质点所属铺层分类，层间牵引-分离本构和界面断裂能尚未加入。
- A9：局部损伤使用存活键体积比定义，状态更新保持不可逆。

这些假设分别对应构造器字段或定理前提，不以未声明的全局公理形式存在。
